JavaScript Darslari

Har bir bo'lim script.js faylidagi izohlangan (comment) kod namunalariga asoslangan. Tugmani bosib natijani ko'ring.

3-dars: Alert

alert() orqali xabar chiqarish.

4-dars: Qiymatlar va o'zgaruvchilar

let/const bilan o'zgaruvchi yaratish va chiqarish.

5-dars: Ma'lumot turlari

Number, String, Boolean, Null, Undefined, Symbol, BigInt, Object, Array.

6-dars: let, const va var

O'zgaruvchi e'lon qilish usullari.

7-dars: Arifmetik, taqqoslash va tayinlash operatorlari

+, -, *, /, %, **, ++, --, ==, ===, +=, -= va h.k.

8-dars: Stringlar

Birlashtirish, template literal, length, toUpperCase, indexOf, substring, split.

9-dars: Mantiqiy operatorlar

&&, ||, ! va shartli xabar (HTML/CSS/Bootstrap kurslari misoli).

10-dars: Turni o'zgartirish (Type Conversion)

Number(), String(), Boolean(), type coercion, truthy/falsy qiymatlar.

11-12-dars: Funksiyalar (declaration, expression, arrow)

Turli usulda funksiya yaratish va chaqirish.

13-dars: Funksiyalar amaliyoti

Juft/toq, eng katta son, teskari son, faktorial, raqamlar yig'indisi.

14-dars: Array

Array yaratish, push/unshift, pop/shift, indeks orqali o'zgartirish, length.

15-dars: Array metodlari

concat(), indexOf(), find(), filter(), map().

16-dars: Objectlar (Objects)

Object yaratish, Dot va Bracket notatsiyasi, yangi property qo'shish, ichma-ich (nested) objectlar.

17-dars: Object metodlari

Object ichida metodlar, this kalit so'zi, Object.keys(), Object.values(), Object.entries(), Object.assign(), Object.freeze() va Object.seal().

18-dars: if-else shart operatori

Conditional statement, if, else if, else va ichma-ich (nested) shartlar.

19-dars: Switch-Case shart operatori

Switch-case shart operatori yordamida turli shartlarni tekshirish.
